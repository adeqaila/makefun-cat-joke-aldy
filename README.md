## Entry

`main.py` writes one line to `/output/entry.txt` (override for local testing
with `CAT_JOKE_OUTPUT=<path>`):

> My cat sat on my resume during a job interview and got hired. I just work here now.

83 characters / 83 bytes, single line, no trailing newline.

## How it works

`main.py` (Python 3, standard library only, no network, no secrets)
validates the joke against the gate (1–200 characters, single line,
not whitespace-only) and writes it — exactly, no trailing newline — to
`/output/entry.txt`. Deterministic: every run writes byte-identical output.

## Entry selection

12 candidates were drafted and run through an internal tournament scored
against the judge brief published in the kit (setup + turn that lands,
laugh-out-loud first read, fresh angle, no padding, retellable the same
day). Winner: the resume/interview joke above (25/25). See
[candidates.md](candidates.md) for the full list, the tournament, and the
slot-2 backups.
